# Vos données

Vos données (uniquement du texte, jamais envoyées nulle part) sont stockées automatiquement dans :

    %LOCALAPPDATA%\alxBudgetDesktop\

Collez ce chemin (avec les %) dans la barre d'adresse de l'Explorateur Windows pour y accéder directement.

## Sauvegarder ou transférer vos données

C'est ce dossier qu'il faut copier si vous voulez :

- garder une copie de sauvegarde,
- transférer vos données sur un autre ordinateur.

## Désinstaller l'application

Supprimer le dossier de l'application (celui contenant `Fluxo.exe`) n'efface pas vos données : elles vivent ailleurs, dans le dossier ci-dessus.
